# presentation_deck

Four slides for non-technical stakeholders: **Problem · Goal · Workflows #1 & #2 · Results** (real responses for NVIDIA, 2026-09-23).

| File | What it is |
|---|---|
| [`presentation_deck.pdf`](presentation_deck.pdf) | The deck as a PDF (one slide per page); GitHub previews it inline |
| [`index.html`](index.html) | Standalone presentation: open in a browser. `→`/`Space` next, `←` back, `N` speaker notes, `F` fullscreen |
| [`slides/`](slides) | Source for each slide (`problem`, `goal`, `workflows`, `results`), speaker notes in `<aside>` |
| [`deck.json`](deck.json) | Slide order and fonts |

To present locally: `python3 -m http.server 8765 --directory presentation_deck`, then open http://localhost:8765.
